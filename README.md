# Генератор образов

Небольшая страница для сочинения коротких кинематографических образов. Случайно выбирает четыре элемента — место, деталь, звук и действие — и собирает из них набросок сцены.

## Как пользоваться

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

- **Бросить** (или клавиша **Пробел**) — выбрать новую комбинацию.
- **Клик по карточке** — зафиксировать её: при следующем броске она не меняется. Повторный клик снимает фиксацию.
- **Сохранить образ** — добавить текущую комбинацию в список «Сохранённые». Список хранится в `localStorage` браузера, крестик убирает запись.

## Как добавить свои варианты

Списки лежат в объекте `DATA` в начале скрипта в `index.html`. Добавьте строку в нужный массив. Новая категория тоже получит карточку, но в текст сохранённого образа попадают только четыре исходные.
